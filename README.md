# java-racingcar-precourse

# 기능 요구사항
- IO 입출력
- [x] 각 자동차에 이름 부여 가능 (입력)
- [ ] 전진하는 자동차 출력시 이름을 같이 출력
- [x] 사용자는 몇 번의 이동을 할 것인지 입력 
- [ ] 경주 완료시 우승자를 알려줌(출력)
  - [ ] 우승자는 한명 이상가능 (조건)
  - [ ] 우승자가 여러명일 경우 쉼표(,)로 구분 (출력형식)
- validation & formating
  - [x] 이름 5자 이하로
  - [x] 자동차 이름은 쉼표를 기준으로 구분
  - [x] 자동차 이름 중복 검증
- 주요 기능
- [ ] 주어진 횟수 동안 n대의 자동차는 전진 또는 stop
- [x] 0~9 사이의 무작위 값 구하기
  - [x] 구한 숫자가 4이상이면 전진
- [x] 에러처리
  - [x] 이름이 5자리 이상
  - [x] 쉼표와 쉼표 사이에 공백일 경우
- [x] 테스트 코드
  - [x] 입력값 검증 validation(오류처리) 테스트
    - [x] 자동차 이름 (,)로 파싱
    - [x] 이름 길이 검증
    - [x] 이름 빈값 검증
    - [x] 이름 중복 검증
  - [x] 자동차 경주 테스트
# 프로그래밍 요구사항
